# Credits

## sabrina-unlock-v2

**This project wouldn't exist without [oddsolutions/sabrina-unlock-v2](https://github.com/oddsolutions/sabrina-unlock-v2).** It provides the bootloader unlock that everything here depends on.

- **Nolen Johnson (npjohnson), Jan Altensen (Stricted) and Ray Volpe (Functioner):** theorizing, developing and chaining together the exploit
- **[k-o-n-t-o-r](https://github.com/k-o-n-t-o-r):** [ghostlock-sabrina](https://github.com/k-o-n-t-o-r/ghostlock-sabrina), the GhostLock implementation for this device
- **BigEmpty @ XDA:** the dual environments in `env`, and CRC calculation
- **P0werpl @ XDA:** pointing to GhostLock and testing the patching method
- **Brian Light:** whitepaper review

Read the [whitepaper](https://oddsolutions.github.io/Chromecast-with-Google-TV-4K-Secure-Boot-Bypass-v2/) for how it works.
